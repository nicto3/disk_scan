# DiskHunter

Программа показывает самые большие файлы и папки на выбранном диске. Интерфейс открывается в браузере, сама программа работает локально на компьютере.

## Скачать для Windows

Откройте раздел **Releases** справа и скачайте `DiskHunter.exe`. Запустите файл — браузер откроет интерфейс программы. Python устанавливать не нужно.

Если релиз пока не опубликован: в **Actions → Build Windows app → Run workflow** можно запустить сборку; готовый `DiskHunter.exe` появится в Artifacts.

## Сборка релиза

Создайте тег версии, например `v1.0.0`, и отправьте его в GitHub. Workflow соберёт автономный exe и приложит его к GitHub Release.

```powershell
git tag v1.0.0
git push origin v1.0.0
```

Удаление по умолчанию настроено через корзину. Если корзина недоступна, интерфейс явно предупредит, что удаление станет безвозвратным.
